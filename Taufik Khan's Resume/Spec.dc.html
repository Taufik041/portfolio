Carousel

01label overlay
Playing
  • Frame: 16:9, radius 18, 1px border, overflow hidden, surface bg.
  • Auto-advance every 7000ms when playing; tick 60ms drives the progress fill (width %). Manual nav / jump resets progress to 0.
  • Overlays: label (top-left) + play state (top-right) on rgba(20,20,22,.55) + blur. Arrows: 42 circle, .45 → .72 on hover.
  • Progress bar: 3px, track rgba(128,128,128,.25), fill accent, width transition .12s linear.
  • Dots (below frame): inactive 8×8 border-strong; active 26×8 accent; width/bg transition .3s. Below: synced title / links / body / tags.

Media slot - four states

video - drifting stripes + play
image - single still
gallery - N items
none - walkthrough coming soon
  • Slot keys off media: 'video' | 'image' | 'gallery' | 'none'. Same component drives carousel frame and project page.
  • Placeholders are striped (135deg, stripe1/stripe2 @ 13px) with a monospace label; video drifts via background-position keyframe.
  • Empty state: dashed border-strong, centered clock glyph, "Walkthrough coming soon" + supporting line.
